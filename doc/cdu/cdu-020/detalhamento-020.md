# CDU002. Sugestão de Encaminhamento

- **Ator principal**: Convivente/Visitante
- **Atores secundários**: Nenhum 
- **Resumo**: Ao fim de um determinado conteúdo educacional existe um botão "Solicitar Encaminhamento Profissional" onde um usuário clica e é levado para outra página.
- **Pré-condição**: Nenhuma
- **Pós-Condição**: O Usuário é levado para uma plataforma externa que lhe guiará da melhor forma à realizar um agendamento ou consulta com profissional que desejar.

## Fluxo Principal
| Ações do ator | Ações do sistema |
| :-----------------: | :-----------------: | 
| 1 - Ao fim de um conteúdo educacional o usuário clica no botão "Solicitar Encaminhamento profissional" | |  
| | 2 - O Sistema rediciona o mesmo para uma plataforma externa(Parceira do Tevejo) onde o mesmo terá a opção de agendar uma consulta com o profissional que desejar. | 

> Obs. as seções a seguir apenas serão utilizadas na segunda unidade do PDSWeb (segundo orientações do gerente do projeto).
