# CDU004. Visualizar discussões públicas

- **Ator principal**: Todos.
- **Atores secundários**: Não existe. 
- **Resumo**: Permite qualquer usuário visualizar discussões públicas disponíveis na plataforma.
- **Pré-condição**: as discussões públicas devem estar disponíveis.
- **Pós-Condição**: Todos pode visualizar os detalhes da discussão, incluindo comentários.

## Fluxo Principal
| Ações do ator | Ações do sistema |
| :-----------------: | :-----------------: | 
| 1 - Acessa a página de discussões públicas| |  
| | 2 - O sistema carrega todo contéudo disponível, ordenando pela data de postagem |
| 3 - Seleciona uma discussão  para visualizar | |
| | 4 - Exibe o conteúdo completo da discussão.

## Fluxo Alternativo I - Nenhum conteúdo postado

| | 2.2 - O sistema não encontra nenhum contéudo disponível e avisa que no momento, não tem nenhuma postagem |
