# CDU012. Gerenciar comunidades

- **Ator principal**: Moderador
- **Atores secundários**: Não existe.
- **Resumo**: O moderador tem recursos para gerenciar a comunidade.
- **Pré-condição**: Tem que ser convivente que criou a comunidade ou concedido pelo dono da comunidade.
- **Pós-Condição**: O moderador altera algum informação da comunidade, ou a exclui

## Fluxo Principal - Alterar Informações de uma Comunidade
| Ações do ator | Ações do sistema |
| :-----------------: | :-----------------: | 
| 1 - Clicar em edição de comunidade| |  
| | 2 - Exibir todas as configurações editáveis e aplicar alterações após confirmação |

## Fluxo Alternativo I - Excluir uma Comunidade
| Ações do ator | Ações do sistema |
| :-----------------: | :-----------------: | 
| 1.1 - Clicar em edição de comunidade| |  
| | 1.2 - Exibir todas as configurações |
| 1.3 - Clicar em excluir comunidade| |
| | 1.4 - Sistema remove a comunidade do banco de dados |
